Hermes Agent

2026-11-03

Hermes Agent is a free, open-source AI assistant that lives on your own computer or server, remembers what it learns, and gets better at your tasks the longer you use it. Use it for always-on personal automation you can reach from Telegram or WhatsApp. For sit-down coding in a codebase, Claude Code is still the stronger tool.

What it is

  • Who makes it: Nous Research, an open-model AI lab known for its own "Hermes" family of language models. The agent shares the name but is a separate product.

  • What it is: an agent "harness", meaning the program that wraps around an AI model and gives it hands (tools), a memory and a way to reach you. You bring the brain: Claude, GPT, Gemini, DeepSeek, Kimi or a model running on your own machine.

  • Released: February 2026, under the MIT license, so it is free to use, copy and change, even commercially.

  • Tagline: "The agent that grows with you." Its big idea is a built-in learning loop: it writes down reusable how-tos (skills) from work it has done and refines them each time.

  • Where it lives: wherever you put it. A $5-a-month cloud server, your laptop, a GPU machine, or pay-when-used cloud sandboxes that sleep when idle. You talk to it from the terminal, a desktop app, or a chat app on your phone.

How it works

Think of Hermes as one assistant sitting in the middle. You reach it from any screen, it thinks with whichever AI model you plug in, and it keeps its own notebook.

The agent loop is the core: it reads your request, decides which tool to use, runs it, checks the result and repeats until the job is done. Everything else serves that loop.

PartWhat it does in plain words
GatewayOne background program that connects Hermes to 20+ chat apps, so a Telegram message and a terminal command reach the same agent
MemoryPlain text files it keeps about facts (MEMORY.md) and about you (USER.md), plus a search over past conversations that it summarises when needed
SkillsStep-by-step how-tos saved as files. It writes new ones from experience and rewrites them when it finds a better way. They follow the open agentskills.io format, so they also work in other agents
SOUL.mdA file that sets its default personality and tone
Context filesProject notes it reads at the start of every conversation, like Claude Code's CLAUDE.md
SubagentsCopies of itself it spins up to work on several things in parallel
ProfilesSeparate Hermes instances, each with its own memory, skills and settings, e.g. one for work and one for personal
Terminal backendsWhere its commands actually run: your machine, a Docker container, a remote server over SSH, or cloud sandboxes (Modal, Daytona) that sleep when idle

The learning loop

This is what makes Hermes different from most agents, which forget everything when the chat ends.

Say you ask it to compile a weekly report from three websites. The first time, it works out the steps by trial and error. Afterwards, a built-in nudge asks it what was worth keeping, so it saves a "weekly report" skill. Next week it loads that skill, skips the trial and error, and updates the skill if a site has changed. Over months, your Hermes collects dozens of these, tuned to how you work.

Install and setup

Easiest: download the Hermes Desktop installer for Windows or Mac from hermes-agent.nousresearch.com. It installs both the app and the command-line tool.

Command line only:

SystemCommand
Linux, macOS, WSL2, Android (Termux)curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
Windows (native, early beta)iex (irm https://hermes-agent.nousresearch.com/install.ps1)

On Windows, WSL2 is the most tested route; native Windows is still early beta.

First run, step by step:

  1. hermes setup --portal signs you in to Nous Portal and gives you a model plus web search, image generation, voice and a browser in one go. Or run plain hermes setup to plug in your own API keys instead.

  2. hermes starts chatting in the terminal.

  3. hermes gateway setup then hermes gateway start connects it to Telegram, WhatsApp or another chat app, so you can message it from your phone.

  4. Coming from OpenClaw? hermes claw migrate imports your memories, skills, API keys and chat settings. Setup also spots an existing OpenClaw folder and offers this automatically.

Everything lives in a ~/.hermes folder on your machine: config, memory, skills and logs, all readable plain files.

Which model to run it on

Hermes works with 200+ models through providers including Nous Portal, OpenRouter, Anthropic, OpenAI, Google, DeepSeek, Kimi, MiniMax, local Ollama, or any OpenAI-compatible server.

Hermes vs Claude Code vs Codex vs OpenClaw

These overlap but are built for different jobs. Hermes is agent-first, OpenClaw is gateway-first, and Claude Code and Codex are coding-first.

How to choose:

  • Writing, debugging and refactoring code in a project: Claude Code (or Codex if you are on OpenAI). They have the best code awareness, tests, Git and IDE support.

  • An assistant that runs 24/7, remembers you, works from your phone and handles mixed tasks (research, reports, monitoring, messages): Hermes.

  • You already run OpenClaw with lots of its 5,000+ community skills: stay, or migrate with one command if you want Hermes's learning loop.

Many people run both: Claude Code for sit-down coding sessions, Hermes for one-off code jobs and everything else on the move.

Costs

The software is free. You pay for three things:

CostTypical rangeNote
Server$4 to $25/month1 GB RAM and 1 CPU is enough when the model runs in the cloud; skip it entirely by running on your own laptop
AI model usage$2 to $60/monthBiggest variable. Premium models can cost about 30x more than budget ones for the same work
Optional toolsA few dollars, or Nous Portal Plus at about $20/monthWeb search, browser, image generation, voice

A light personal setup runs $5 to $8 a month; heavy use on premium models reaches $80+. Managed hosting (for example Hostinger) starts around $6/month if you do not want to run a server.

Two cost traps: chatting through Telegram or other apps uses roughly 15,000 to 20,000 tokens per turn, versus 6,000 to 8,000 in the terminal, because of the extra context; and hourly-billed cloud servers left on 24/7 add up fast.

Limitations

  • Not the best coder. For deep work inside a codebase, Claude Code and Codex are stronger.

  • Setup and upkeep are on you. Models, keys, server, updates and security settings are your job unless you pay for managed hosting.

  • Young project. Released February 2026 with frequent releases; features and commands change quickly.

  • Native Windows is early beta. Use WSL2 or the desktop app.

  • Quality depends on the model. Cheap or local models stumble on long multi-step tasks, and a mistake early on can derail the whole run.

  • Memory can go wrong. It decides itself what to save, so it can keep something wrong or private and reuse it later.

  • Costs can creep. Long autonomous runs (now up to 500 tool steps by default) and chat-app usage burn tokens.

Security

Hermes can run commands, read files, browse, and message people with whatever access you give it, so treat it like a server, not a chat app.

  • The only real wall is your operating system. Nous's own security policy calls Hermes a single-person agent whose true safety boundary is OS-level isolation. By default it runs commands on your machine with your permissions.

  • Run it in a box. Use the Docker or a remote backend, not your main laptop's local shell, for anything serious.

  • Review skills before installing. Skills and plugins run with full agent access. The built-in Skills Guard scanner helps but is not a guarantee.

  • Lock down who can talk to it. Use allowlists and pairing so only you can message your agent.

  • Keep approvals on for risky terminal commands.

  • Audit its memory now and then in ~/.hermes, and delete what it should not keep.

  • Known bugs happen. Public vulnerabilities have included a path-traversal flaw (CVE-2026-7396) that let it read files outside its folder; keep it updated.
